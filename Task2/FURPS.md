| Код | Требования                         | Комментарий |
|-----|------------------------------------|-------------|
| **F**   | **Функциональные (Functionality)**     |             |
| F1  | Новый клиент может видеть на сайте список доступных депозитов с актуальными ставками|Важно обеспечить актуальность данных ставок|
| F2  | Клиент может подать заявку на депозит через сайт, оставив свой номер телефона и Ф. И. О.|Чувствительная информация требует шифрования трафика|
| F3  |  Менеджер кол-центра может видеть заявки в системе и предложить по ним особые условия|             |
| F4  | Обязательно принимать новых клиентов в отелении банка для идентификации|Банки не могут принимать новых клиентов без личной проверки документов|
| F5  | Клиент может видить список доступных депозитов с актуальными ставками и персонализированные ставки лично для него в интернет-банке |             |
| F6  | Клиент может подать заявку на открытие депозита, указав счёт и сумму депозита|Данные при передаче требуют шифрования|
| F7  |  Клиент должен подтвердить заявку на открытие депозита через интернет-банк с помощью СМС-кода.|Наличие функционала для работы с СМС|
| **U**   | **Удобство использования (Usability)** |             |
| U1  |  Интерфейс должен быть максимально удобным для клиента|Проработка UX/UI дизайна, анализ имеющихся на рынке решений, проведедние А/В-тестирования |
| U2  | Интерфейс открытия депозита должен быть максимально удобным для клиента.|Проработка UX/UI дизайна|
| U3  | Быстрый отклик на действия клиента|             |
| **R**   | **Надёжность (Reliability)**           |             |
| R1  | Все сервисы должны работать 24/7 с доступностью 99,9%.|Необходимо обеспечить отказоустойчивость интернет-банка, предусмотреть использование резервного ЦОД|
| R2  | Все сервисы должны быть доступны 99,9%.|Необходимо обеспечить отказоустойчивость интернет-банка, возможность горизонтального масштабирования|
| **P**   | **Производительность (Performance)**   |             |
| P1  | Быстрый отклик по всем операциям, занимать милисекунды|Сейчас при проведении платежей некоторые справочные данные загружаются больше секунды|
| **S**   | **Поддерживаемость (Supportability)**  |             |
| S1  | Рассмотреть возможность перевода интернет-банка на микросервисную архитектуру|Только в рамках задачи открытия депозитов|
| S2  |Предусмотреть разработку документации для дальнейшего расширения системы|Документация должна быть подробной и понятной для разработчиков.|
| **+R**  | **+ Ограничения (Restricitions)**      |             |
| +R1 | Необходимо использовать технологии, которые уже есть в банке. Новые технологии должны быть совместимы с существующими платформами разработки и по ним должна быть экспертиза| Например, базы данных MS SQL и Oracle|
| +R2 | Данные клиента и заявки должны быть зашифрованы при передаче и хранении.|Использовать шифрование данных и закрытый контур|
