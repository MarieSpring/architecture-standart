### <a name="_3bfxc9a45514"></a>**Функциональные требования**

|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
|1|Клиент|Подача заявки на депозит|Клиент может оставить заявку на депозит на сайте (номер телефона, ФИО) и через интернет-банк (счет, сумма депозита)|
|2|Сотрудник кол-центра|Обработка заявки на депозит|Сотрудник кол-центра получает инфрмацию о заявке с сайта и связывается с клиентом, предлагая условия|
|3|Клиент|Идентификация в отделении банка|Новый клиент обязательно проходит идентификацию в отделении банка|
|4|Клиент|Просмотр доступных депозитов|Клиент может видеть список доступных депозитов с актуальными ставками на сайте и в интернет-банке|
### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

|**№**|**Требование**|
| :-: | :- |
|1|Данные клиентов должны быть зашифрованы при передаче|
|2|Операции должны выполняться с минимальной задержкой (миллисекунды)|
|3|Должна использоваться существующая инфраструктура|
|4|Система должна быть доступна 99,9% времени|
|5| Все сервисы должны работать 24/7|
|6|Избегать прямой работы интернет-банка с API АБС в новом процессе|
### <a name="_qmphm5d6rvi3"></a>**Решение**

Диаграммы контекста и контейнеров представлены в файле [C4.drawio](C4.drawio)

Для минимизации затрат и ускорения разработки используются уже имеющиеся технологии (MS SQL, Oracle).
Расчёт ставок и обработка заявок автоматизированы в АБС для исключения ручных процессов.
Для обеспечения гибкости и масштабируемости системы взаимодействуют через API.
 Используются механизмы шифрования для защиты данных при передаче.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Рассмотреть возможность использования Kafka для асинхронной обработки. Это даст преимущество в производительности за счет асинхронной обработки.
Так же рассмотреть возможность выноса депозитных ставок в отдельный сервис - на текущем этапе сложнее в реализации, отолжить на будущее.

**Недостатки, ограничения, риски**

Возможность масштабировать АБС только вертикально при увеличении нагрузки ограничивает производительность.
Если вынести работу со ставками по депозитам в отдельный новый сервис, можно избавиться от Excel-файлов и автоматизировать расчет ставок по депозитам.
 Работ в одном ЦОД не гарантирует 99,9% доступности.
